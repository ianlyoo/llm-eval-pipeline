Overview

Offline evaluation hub for Self-Evolve loops. Generate controlled synthetic QA from chunks, run deterministic Rule checks, validate evidence sufficiency with an LLM Judge, accumulate failures into a taxonomy, and compare before/after with lm-eval and PyTorch — all offline and reproducible.

  • Python 3.11, rule-based synthetic QA without API keys (LLM provider optional fallback)
  • Verifiable taxonomy and fail-closed metrics (Hit@5 / faithfulness proxy)
  • Stable data contract consumed by rag-ops-console

Evaluation — Measured vs Target (fail-closed)

Measured baseline (Deterministic Proxy): Hit@5 0.66 / faithfulness 0.8034 from out/metrics_report.json (50 samples, proxy-expected_keyword). Target after is projected, not measured.

Limitations adjacent to benchmark: Synthetic QA, rule-based generation, deterministic metrics are token-overlap proxy not LLM-backed RAGAS; one 50-sample run; no training improvement measured in this iteration; out/improved_metrics.json intentionally absent — scripts/compare_rag.py fails closed without two distinct measured artifacts. Do not treat Target as measured.

Pipeline — synthetic → rule → judge → taxonomy → lm-eval

  • Synthetic data eval/synthetic_data.py — 6 templates, dedup ≥0.8, every QA carries source_chunks
  • Rule filter eval/rule_filter.py — deterministic pass/fail
  • LLM Judge eval/llm_judge.py — evidence sufficiency (OpenAI-compatible)
  • Taxonomy eval/metrics.py — accumulate failures → next-batch fixes
  • lm-eval before/after eval/pytorch_experiment.py — training effect when measured
