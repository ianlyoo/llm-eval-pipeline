# Nimbus Note — Product FAQ

## What is Nimbus Note?
Nimbus Note is a cloud-based note-taking and task management app with real-time collaboration.

## Pricing
- Free: up to 100 notes, 1GB storage.
- Pro: $8/month, unlimited notes, 50GB, version history 1 year.
- Team: $15/user/month, SSO, admin console, priority support.

## Sync & Offline
- Syncs across Web, iOS, Android, Desktop (Windows/macOS).
- Offline mode caches last 500 notes; changes sync when online.

## Export
- Export to Markdown, PDF, or HTML. Bulk export up to 1000 notes at once.

## Collaboration
- Share with view/comment/edit permissions. Comment threads resolve per paragraph.

## Security
- Encryption at rest (AES-256) and in transit (TLS 1.3). 2FA via TOTP.

## Support
- Help center: help.nimbus.example, email: support@nimbus.example.
- Response SLA: Free 72h, Pro 24h, Team 4h.
